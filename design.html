Dependency Rule

  • • Domain tidak import application/infra — nol dependensi keluar
  • • Application depend ke Domain (entity + VO + repo interface)
  • • Infra depend ke Domain (implements interface)
  • • Presentation depend ke Application (wire use-case)

SOLID yang kepakai

  • • SRP — 1 use-case = 1 class (CreateTask ≠ UpdateTask)
  • • OCP — tambah gateway/repo tanpa ubah use-case
  • • DIP — use-case terima interface, bukan concretion
  • • ISP — repo interface kecil & fokus

Swap tanpa ubah domain

  • • InMemory → Postgres/Prisma (implement repo sama)
  • • Scrypt → bcrypt/argon2 (implement PasswordHasher)
  • • HMAC → JWT lib (implement TokenIssuer)
  • • ToggleGateway → Xendit/Stripe (implement PaymentGateway)

API surface

  • • Auth: POST /auth/register|login, GET /auth/me
  • • Order: POST/GET /orders, POST /orders/:id/pay|cancel
  • • Semua validasi di Value Object (fail fast)
